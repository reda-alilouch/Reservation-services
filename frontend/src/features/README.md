# Fonctionnalités métier

Chaque dossier regroupe les composants, hooks et logique propres à une fonctionnalité :

- `auth/` : connexion, inscription et session.
- `hotels/` : hôtels.
- `rooms/` : chambres.
- `reservations/` : réservations.
- `provider/` : espace prestataire.
- `admin/` : espace administrateur.
