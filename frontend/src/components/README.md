# Composants

- `layout/` : éléments structurels réutilisables, par exemple `Navbar`, `Footer` et `DashboardSidebar`.
- `ui/` : composants génériques sans logique métier, par exemple `Button`, `Input`, `Modal` et `Badge`.
- `shared/` : composants communs à plusieurs fonctionnalités, par exemple `EmptyState` et `DataTable`.
